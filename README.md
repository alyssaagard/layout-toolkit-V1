# Layout Toolkit is now Offizin

This was the Word on the web edition of Layout Toolkit. It has been replaced by **[Offizin](https://github.com/alyssaagard/offizin)**, which brings Word (web, Windows, and Mac) and Google Docs together in one project.

Offizin 2.0 adds 18 publications (up from 6), color and font schemes, business information sets, page parts, picture placeholders, a design checker, folding guides, and a live demo you can try without installing anything.

- Website and live demo: https://alyssaagard.github.io/offizin/
- Install for Word: https://alyssaagard.github.io/offizin/word/
- Install for Google Docs: https://alyssaagard.github.io/offizin/google-docs/
- Source code: https://github.com/alyssaagard/offizin

## If you installed Layout Toolkit

It keeps working, and it now shows a note pointing to Offizin. To switch, install Offizin from the Word page above, then remove Layout Toolkit under Home, Add-ins, My Add-ins (or delete its manifest from the wef folder on a Mac).

This repository is kept for reference and no longer receives updates.
